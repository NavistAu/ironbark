# ironbark M3 — `ib` local client — implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `cmd/ib` exactly as specified in [`docs/CLIENT-SPEC.md`](../CLIENT-SPEC.md).
**CLIENT-SPEC is the source of truth; this plan sequences it.** Where the two
disagree, stop and report — do not pick one.

**Architecture:** A second binary in the same module. It resolves an identity
from the git checkout, chooses a branch tier (CLIENT-SPEC §3), and runs the
broker's own sweep (`internal/vaultx`) with the caller's token. No sweep,
naming, deref or pin logic is re-implemented in `cmd/ib`.

**Tech stack:** Go (module's `go` version), stdlib only for new code
(`flag`, `os/exec`, `os/signal`, `io`), `github.com/hashicorp/vault/api`
(already a dependency). No new module dependencies.

**Plan style:** a spec, not a diff. Steps give signatures, behaviours, test
cases with expected results and commands; the implementer writes the code.

**Conventions for every task:** TDD (failing test → fail → implement → pass →
commit). `go test ./internal/... -run <Name> -v`; full `go test ./...`;
`go vet ./...`. Conventional commit prefixes. The broker's existing tests must
stay green after every task — the shared code is shared.

## Task 1: `vaultx` — the shared-code seams

The broker keeps its exact behaviour; each change is additive.

- [ ] **TLS.** `vaultx.Config` gains `TLS *api.TLSConfig`. `New` calls
  `ConfigureTLS` on the `api.Config` it builds when `TLS` is non-nil, before
  `api.NewClient`. Nil (the broker) = today's behaviour. Test: a `httptest`
  TLS server with its own CA — a client with `TLS{CACert: <file>}` reads it;
  one without fails with a certificate error.
- [ ] **Lease IDs.** `SweptSecret` gains `LeaseID string` (set on every secret
  flattened from a deref whose response carried a `lease_id`; empty
  otherwise). `SweepResult` gains `LeaseIDs []string` (distinct, creation
  order). `LeasesCreated` stays and stays true iff `len(LeaseIDs) > 0`.
  Test: fake deref target returning `lease_id: "aws/creds/x/abc"` with two
  fields → both secrets carry the ID, `LeaseIDs == ["aws/creds/x/abc"]`.
- [ ] **Partial result on error.** When `Sweep` fails after one or more derefs
  created leases, it returns the error AND a `SweepResult` whose `LeaseIDs`
  lists them (secrets may be empty). The broker ignores the result on error
  (it revokes the minted token, cascading the leases) — assert its behaviour
  is unchanged. Test: tier 1 deref creates a lease, tier 2 LIST returns 500
  → error non-nil, `LeaseIDs` has the one ID.
- [ ] **`ListBranchTiers(ctx, token string, id identity.Identity) ([]string, error)`.**
  LISTs `<mount>/metadata/<Base(id)>/<id.Event>` and returns the *directory*
  keys (trailing `/` stripped), still escaped (SPEC §2.2), sorted. 403/404 →
  `nil, nil`. Other status → error. Dot-prefixed keys excluded. Test cases:
  mixed plain + dir keys → only dirs; 403 → empty; 500 → error.
- [ ] **`RevokeLeases(ctx, token string, ids []string) []error`** (new
  `leases.go`): `PUT sys/leases/revoke` with body `{"lease_id": id}` per ID,
  caller's token; one error slot per failed ID, nil slice when all succeed.
  Never calls `auth/token/revoke-self`. Test: fake records path, method, body
  and token for each ID; a 403 on one ID yields one error, others still sent.

**Verify:** `go test ./...` green, including `internal/broker` and
`test/integration` (if docker is available — otherwise note it and run in CI).

## Task 2: `identity.ParseRemote`

- [ ] `ParseRemote(url string) (org, repo string, err error)` in
  `internal/identity/remote.go`. Accepts exactly the three CLIENT-SPEC §2
  forms; org/repo are the last two path segments, `.git` suffix stripped,
  lowercased; host, port and user ignored.
- [ ] Table test, expected `(org, repo)`:
  `https://git.example.com/Acme/Widgets.git` → `acme, widgets`;
  `https://git.example.com:8443/acme/widgets` → `acme, widgets`;
  `ssh://git@git.example.com:2222/acme/widgets.git` → `acme, widgets`;
  `git@git.example.com:acme/widgets.git` → `acme, widgets`;
  `git.example.com:acme/widgets` → `acme, widgets`.
  Errors: `""`, `https://git.example.com/widgets` (one segment),
  `/local/path/repo`, `file:///x/y`.

## Task 3: `internal/envfile`

- [ ] `type Entry struct { Key, Value string; Line int }`;
  `Parse(r io.Reader) ([]Entry, error)` per CLIENT-SPEC §1.4 env-file syntax:
  quote-aware (a closing quote ends the entry, newlines inside quotes are
  kept), `#`/blank lines outside quotes skipped, key regex
  `[A-Za-z_][A-Za-z0-9_]*`, single quotes with `'\''` as the only escape,
  double quotes stripped with no escape processing. Errors carry the line
  number: unterminated quote, bad key, missing `=`.
- [ ] `Format(name, value string) string` → `SECRET_<UPPER(name)>='<value>'`
  with `'` → `'\''`, newline-terminated.
- [ ] `Ref(value string) (name string, ok bool)` — exact prefix
  `ironbark://`, name must match `[a-z0-9_]+`, else `ok=false` (passed
  through as a literal by the caller).
- [ ] Tests: round trip — for values `plain`, `it's`, `a\nb`, `''`, `$HOME`,
  `x=y`, `Format` then `Parse` returns the same value; `Ref` accepts
  `ironbark://aws_key`, rejects `ironbark://AWS`, `ironbark:/x`,
  ` ironbark://x`.

## Task 4: `internal/mask`

- [ ] `NewWriter(dst io.Writer, values []string) *Writer`;
  `(*Writer).Write([]byte) (int, error)`; `(*Writer).Flush() error`.
  Values shorter than 4 bytes are ignored; matching is longest-value-first;
  each match is replaced by `<concealed by ib>`. The writer holds back at
  most `maxLen-1` trailing bytes between writes so a value split across
  writes is still caught; `Flush` emits the held tail (masked).
  `Write` reports `len(p)` on success (callers such as `io.Copy` need it).
- [ ] Tests: value split across two writes at every offset → fully masked;
  values `abcd` and `abcdef` with input `xabcdefx` → one placeholder, no
  `ef` leak; value of length 3 → untouched; no values → byte-identical
  passthrough; `Flush` with no pending bytes → no output.

## Task 5: `gitenv` — pure selection

- [ ] `var Cascade = []string{"dev","develop","development","test","testing","qa","uat","stage","staging","preprod","trunk","main","master","prod","production","live"}` (CLIENT-SPEC §3 rule 5, exact).
- [ ] Types:
  - `SelectInput{Override, Current string; Detached bool; Tracked []string; Distance map[string]int; ReflogFrom string}` —
    `Tracked` = git branch names whose escaped form is a visible branch tier;
    `Distance` holds only tracked branches that have `origin/T` and share
    history with `HEAD`; `ReflogFrom` = short branch name or "".
  - `Selection{Branch, Rule, Detail string}`; `Rule` ∈ `override`, `direct`,
    `nearest`, `reflog`, `cascade`, `no-branch-tiers`.
  - `SelectError{Kind string; Candidates map[string]int}` implementing
    `error`; `Kind` ∈ `not-tracked`, `ambiguous`, `no-ancestor`,
    `override-without-tiers`.
- [ ] `Select(in SelectInput) (Selection, error)` — CLIENT-SPEC §3 in order,
  including the "no branch tiers at all" paragraph (`len(Tracked)==0` →
  `no-branch-tiers` selection with empty branch; with an override → error).
  Reflog step skipped when `Detached`.
- [ ] Table tests (Tracked = `main, develop` unless stated):
  | case | input | expect |
  |---|---|---|
  | override hit | Override `develop` | develop / override |
  | override miss | Override `stage` | not-tracked |
  | direct | Current `main` | main / direct |
  | nearest | Current `feat/x`, dist develop 3, main 13 | develop / nearest |
  | tie→cascade | Current `fix/y`, dist 2/2, no reflog | develop / cascade |
  | tie→reflog | same, ReflogFrom `main` | main / reflog |
  | detached tie | Detached, dist 0/0, ReflogFrom `main` | develop / cascade |
  | tie off-list | Tracked `alpha, beta`, dist 1/1 | ambiguous {alpha:1,beta:1} |
  | no ancestor | Distance empty, Current `orphan` | no-ancestor |
  | no tiers | Tracked empty | "" / no-branch-tiers |
  | no tiers + override | Tracked empty, Override `main` | override-without-tiers |

  (Cascade puts `develop` before `main`, so the untie-able `fix/y` goes to
  the lower environment — intended, CLIENT-SPEC §3.)

## Task 6: `gitenv` — git adapter

- [ ] `type Runner interface { Git(args ...string) (string, error) }` with an
  exec implementation bound to a directory (trimmed stdout; stderr in the
  error).
- [ ] `Checkout(r Runner) (CheckoutInfo, error)`: `TopLevel` via
  `git rev-parse --show-toplevel`; `Branch` via `git symbolic-ref -q --short
  HEAD` (empty + `Detached=true` when it fails); `OriginURL` via
  `git remote get-url origin`. Not a checkout / no origin → typed error
  (exit 2 upstream).
- [ ] `Facts(r Runner, current string, tiers []string /*escaped*/) (tracked []string, dist map[string]int, reflogFrom string, stale []string, lsRemoteErr error)`:
  - tracked: `git for-each-ref --format=%(refname:short) refs/remotes/origin`,
    strip `origin/`, skip `origin/HEAD`, keep those whose `identity.Esc` is in
    `tiers`; also include `current` if its escape is in `tiers` (direct match
    works without a remote-tracking ref).
  - dist: for tracked T with `origin/T`: `git merge-base HEAD origin/T`
    (non-zero exit = no common history → omit); `git rev-list --count
    origin/T..HEAD`.
  - reflogFrom: last line of `git reflog show --format=%gs refs/heads/<current>`
    matching `branch: Created from <ref>`; normalise `refs/heads/`,
    `refs/remotes/origin/`, `origin/` prefixes away; `HEAD` or a SHA → "".
  - stale: one `git ls-remote --heads origin`; each tracked T whose
    `origin/T` SHA differs from the forge's → listed. `ls-remote` failure →
    `lsRemoteErr` set, `stale` nil (the caller warns "freshness unknown").
- [ ] Tests on scripted fixture repos in `t.TempDir()` (a bare "forge" repo +
  a clone; set `user.name/email` locally; no network): branch cut from
  `develop` (distance 3 vs 13); worktree (`git worktree add -b feat wt develop`)
  → same facts from inside the worktree and reflog `develop`; detached HEAD;
  orphan branch (no ancestor); a forge branch advanced after the clone's
  fetch → `stale` lists it; `origin` pointing at a non-existent path →
  `lsRemoteErr` non-nil.

## Task 8: `cmd/ib` — resolve pipeline, `get`, `env`

- [ ] `resolve(ctx, opts) (secrets map[string]vaultx.SweptSecret, leaseIDs []string, err error)`:
  ibcfg → Checkout → `ParseRemote` → identity `{Org, Repo, Event:"push", Branch}`
  → `ListBranchTiers` → Facts → stale/freshness warnings → `Select` → stderr
  line (`ib: env <branch> (<rule>, <detail>)`, or the no-branch-tiers line)
  → `Sweep(ctx, token, id, branchful = branch != "")` → drop secrets whose
  `Events` is non-empty and lacks `push` → map by name. Images ignored.
- [ ] Exit-code mapping in one place (CLIENT-SPEC §7): usage 1; config /
  checkout / remote 2; unknown name 3; `SelectError` 4 (message lists
  candidates with distances and asks for `--branch`); sweep error 5 (after
  revoking any `LeaseIDs` from the partial result).
- [ ] `--branch` is a flag on `get`, `env`, `run`; `IB_BRANCH` is the
  fallback; flag wins.
- [ ] `get <name>`: value to stdout; trailing newline iff stdout is a
  character device (`os.Stdout.Stat()`); unknown name → 3. Leases → stderr
  note that they expire on TTL.
- [ ] `env`: every secret, sorted by name, via `envfile.Format`; same lease
  note.
- [ ] Tests: `resolve` against a `httptest` fake Vault + a fixture repo
  (reuse Task 6 helpers) — secrets from the chosen tier, pin filtering
  (`ironbark_events: cron` dropped, `push,cron` kept), unknown name → 3,
  ambiguous → 4 with both candidates in stderr.

## Task 9: `cmd/ib run`

- [ ] Flags: repeatable `--env-file`, `--no-masking`, `--branch`; everything
  after `--` is the command (missing → usage, exit 1).
- [ ] Environment = `os.Environ()`, then each file's entries in order (later
  wins); a `Ref` value is replaced by the secret; any unresolved ref → exit 3
  before starting the child. `resolve` runs once, only if at least one ref
  exists.
- [ ] Child via `os/exec`; stdin inherited. Masking on: stdout/stderr piped
  through two `mask.Writer`s (values = every resolved ref value), flushed
  after exit. `--no-masking`: stdio inherited.
- [ ] Forward SIGINT, SIGTERM, SIGHUP to the child; exit with the child's code
  (signal-terminated → 128+signal).
- [ ] After exit: `RevokeLeases` on the lease IDs of the secrets actually
  used; failures → stderr, exit code unchanged.
- [ ] Tests (build the binary in `TestMain`, run a tiny helper command via
  `os.Args[0]` re-exec pattern): ref resolved into child env; literal passed
  through; unresolved ref → 3 and child never ran; masking hides a value split
  by the child across two writes; `--no-masking` shows it; child exit 7 →
  `ib` exits 7; SIGTERM to `ib` reaches the child.
